## Design

Move adapter/database/event-bus construction, initial repository seeding and recovery, scheduler/active-workflow bookkeeping, and shutdown ownership into `apps/api/src/container.ts`. `AppContainer` explicitly exposes the repository, event bus, adapters and RunOrchestrator needed by route registrars. Fastify's `app.ts` retains only transport setup, CORS, request-ID header, route registration and the onClose bridge.

Keep `BuildAppOptions` exported from `app.ts` for the existing demo runtime's type-only import and test compatibility, while declaring its actual interface in `container.ts`. Preserve externally injected SQLite ownership: container shutdown cancels pending workflows and waits for started work but only closes the database if the container created it.
